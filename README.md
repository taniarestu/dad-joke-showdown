Entry for the [make.fun bounty "Dad Joke Showdown"](https://make.fun/c/u-mfnakmal-dad-joke-showdown-1d2ce3e5) ($5, closes 26 Nov 2026).

## The entry

> The electrician wired my house for sound, and now every room is current.

One dad joke, 72 characters: the pun ("current") lands cleanly on first
read, the punchline arrives at the end, and it reads naturally aloud across
a dinner table.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```
